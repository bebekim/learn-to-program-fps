## Explain it together

A first-person image can be assembled by repeating the one-ray/one-column operation across the screen. Each column looks in a slightly different direction.

Keep the chain visible: screen column → ray direction → wall distance → projected height → characters in that column. The renderer does not need to know whether the player arrived by keyboard or an automated test.

This lab prints one static ASCII frame. It is not a real-time console engine or a finished FPS. Its purpose is to expose the geometry using the same model that a raylib view could visualise.

## Worked example — predict before running

For a 60-degree field of view, the left side looks roughly 30 degrees left of the centre direction and the right side roughly 30 degrees right. The centre ray follows the player heading.

The helper samples column centres:
offset = ((column + 0.5) / width - 0.5) × field_of_view.
With width 3, offsets are -20°, 0°, +20°. They are not the outer edges -30° and +30°.

Radial ray distance increases towards the edge when looking at a flat front-facing wall. For projection, use perpendicular camera depth = radial distance × cos(offset). Otherwise the wall can appear curved: the familiar fisheye distortion.

## Guided practice

1. Draw a fan of three rays on paper.
2. Read render's loop while keeping cast_ray covered as an understood helper.
3. Run the starter and identify rows and columns in the output.
4. Change field of view from 60 to 90 degrees; predict that the sampled directions spread farther apart.
5. On a saved copy, replace depth correction with raw radial distance and compare the wall appearance.
6. Restore correction and explain which quantity feeds projection.

The lab uses a simple height scale and fixed sample stepping. Do not present the image as a physically complete camera.

## Independent challenge

Change only camera position while keeping the map fixed. Sketch which wall should become nearer, then compare its apparent height.

Ask for a prediction before execution. Offer one hint at a time; do not reveal the
target as the answer to the independent challenge.

## Instructor answers and troubleshooting

The target widens FOV only. Exact visible shapes are generated by the sample-based renderer; the exercise prediction concerns ray spread and relative wall appearance.

If every column uses the same ray angle, every column receives the same wall distance. The image may become a uniform band, a useful diagnostic linking repeated input to repeated output.

Perpendicular wall depth must remain consistent with the object-depth convention used in lesson 24.

The target changes field of view to 90 degrees; it does not add animation or keyboard controls.
